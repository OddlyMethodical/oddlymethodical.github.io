# OddlyMethodical

A small, buildless GitHub Pages portfolio. Only public project information is included.

Edit `index.html` for the bio, projects and links; edit `style.css` for the design. GitHub Pages serves the `main` branch root. No packages, trackers, cookies, external fonts or API credentials are needed.

The four featured demos were checked on 24 October 2026. Lily Pad and Fourier Playground have public demos and private repositories, so only their demos are linked. Add future projects to `index.html`; the “all public repositories” link always opens the current GitHub list.

Check with `node --test test.cjs`. Preview with any static web server, or open `index.html` directly.
